> **状态**：迁移完成 ✅（交叉编译 + 板端 smoke + 全链路 A/V 通话全部通过）
> 日期：2026-05-22
> 关联文档：[plan.md](plan.md) · [oplog.md](oplog.md) · Phase 0–8 summary

## 一、背景

v0.3.3 的 RV1126B 移植（Phase 0–8）完成于 `port/rv1126b-on-upstream-v0.3.3`。
upstream `livekit/client-sdk-cpp` 发布 v0.3.4 后，把这套移植前移到 v0.3.4。

v0.3.3 → v0.3.4 的 upstream 改动：140 个文件、+5790/−8200 行。**最大的结构
变化是 `examples/` 整个目录被移出 SDK 仓库**，改为独立的
`cpp-example-collection` submodule（`livekit/client-sdk-cpp-examples`）；
`bridge/` 仍保留。

## 二、三仓库分支布局

v0.3.3 时移植只动 2 个仓库。v0.3.4 因为 examples 外置，变成 **3 个仓库**：

| 仓库 | v0.3.4 移植分支 | 内容 |
|---|---|---|
| `John-Shao/livekit-sdk-cpp` | `port/rv1126b-v0.3.4` | SDK 交叉编译支持 + `Room::Disconnect()` + video_frame 修复 + scripts + docs |
| `John-Shao/livekit-sdk-rust` | `port/rv1126b-v0.3.4` | MPP 硬件编解码（webrtc-sys / livekit-ffi colorcvt） |
| `John-Shao/livekit-cpp-examples` | `rv1126b-v0.3.4` | `board_loopback` 产品 App（多人会议客户端） |

`livekit-sdk-cpp` 的两个 submodule（`client-sdk-rust`、`cpp-example-collection`）
URL 指向 John-Shao fork，gitlink 指向上面的移植分支。

## 三、迁移方法

### rust —— 干净 rebase

`port/rv1126b-mpp` 的 20 个 MPP 移植 commit 直接
`git rebase --onto 8d4d069a fd3df87`（8d4d069a = v0.3.4 cpp 锚定的 rust commit）。
**冲突面为空** —— 移植碰过的 17 个文件（`webrtc-sys/src/rockchip_mpp/*`、
`webrtc-sys/build.rs`、`peer_connection_factory.cpp`、`video_*_factory.cpp`、
`video_frame_buffer.rs`、`imgproc/colorcvt`、`livekit-ffi/.../colorcvt`）没有一个
被 v0.3.4 upstream 改过。`WEBRTC_TAG` 在 v0.3.3/v0.3.4 都是 `webrtc-7af9351`，
无 cxx-bridge 枚举漂移风险。

### cpp —— curated 重新应用

v0.3.3 移植分支有 91 个非 docs commit，绝大多数是 `board_loopback` App 演进 +
docs。因 v0.3.4 目录结构大变（examples 外置），不做盲目 rebase，改为按逻辑
重新应用移植 delta（23 个非 docs 文件）成 6 个 curated commit：

1. `port(rv1126b): CMake aarch64 cross-compile support`
2. `port(rv1126b): SDK Room::Disconnect() for synchronous server-side leave`
3. `port(rv1126b): VideoFrame::fromOwnedInfo stride-strip on multi-plane copy`
4. `port(rv1126b): operational scripts`
5. `docs(port): import RV1126B port docs`
6. `port(rv1126b): bump submodules to v0.3.4 port branches`

**冲突面**（移植碰过且 v0.3.4 也改过的文件）共 8 个，全部区域不重叠、手工
对账后干净落地：

| 文件 | upstream v0.3.4 改动 | 移植改动 | 处理 |
|---|---|---|---|
| `CMakeLists.txt` | line 359/373/696（trace 源文件、examples 外置） | line 90–306（交叉编译） | 区域不重叠，直接应用 |
| `cmake/protobuf.cmake` | 未改 | host protoc + aarch64 abseil flag filter | 干净应用 |
| `.gitignore` | `local-install/` `*trace.json` 等 | `.token` / recon 产物 | 合并 |
| `include/livekit/room.h` | 无关区域 | `Disconnect()` 声明 | 干净插入 |
| `include/livekit/room_event_types.h` | 加 `PacketTrailerFeatures` | 补全 `VideoCodec` enum | 区域不重叠 |
| `src/room.cpp` | clang-tidy 整理 + `setOnVideoFrameEventCallback` | `Room::Disconnect()` 实现 | 干净插入 |
| `src/ffi_client.cpp` | clang-tidy 整理 | `disconnectAsync()` | 干净插入 |

### examples —— board_loopback 落到独立仓库

v0.3.3 的 `examples/board_loopback/main.cpp`（2752 行）+ `third_party/httplib.h`
搬进 `cpp-example-collection` fork，作为新的 example 目录 `board_loopback/`：
`main.cpp` + `httplib.h` + `CMakeLists.txt`，根 `CMakeLists.txt` 加

## 四、v0.3.4 新增的移植改动（v0.3.3 没有）

examples 外置带来 2 处 v0.3.3 不存在的新移植改动：

1. **`cmake/cpp-example-collection.cmake` 传播交叉工具链** —— v0.3.4 把
   example collection 配成一个**独立的 CMake 子项目**（`livekit_configure_cpp_example_collection`
   用 `add_custom_target` 单独 configure + build）。上游只传 `CMAKE_OSX_ARCHITECTURES`，
   交叉编译时不传 `CMAKE_TOOLCHAIN_FILE` → 嵌套 build 会**默默按 host 架构编**。
   移植补丁：`CMAKE_CROSSCOMPILING` 时把 `CMAKE_TOOLCHAIN_FILE`（解析成绝对路径）
   追加进嵌套 configure 参数。

2. **`scripts/smoke.sh` 适配当前板子镜像** —— 板子固件（kernel `#29`，
   `-g4a1fe4ec`）的 busybox 比 v0.3.3 时更精简：
   - 无 `stdbuf` → `command -v stdbuf` 探测，缺失则不加缓冲前缀。
   - 无 `pkill` → 改用 init 脚本 `stop` + `pidof` + `kill`。
   - 出厂 IPC 固件的 `camera_core_d` 占用**摄像头 + DRM + 8080 端口**，
     `camera_ui_d` 占 DRM。smoke.sh 跑前用 `/etc/init.d/S95camera-core-d stop`
     / `S96camera-ui-d stop` 让出硬件。

## 五、交叉编译（VM 192.168.126.129）

VM 复用 v0.3.3 的一次性环境（Buildroot toolchain、`~/webrtc-prebuilt`、
`~/lk-deps`、host protoc）。v0.3.4 的 vendored 依赖版本与 v0.3.3 **完全一致**
（protobuf 25.3 / abseil 20240116.2 / spdlog 1.15.1），无需重建。

```bash
# SDK
cmake -S . -B build-rv1126b \
  -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/rv1126b-aarch64-linux-gnu.cmake \
  -DCMAKE_BUILD_TYPE=Release -DLIVEKIT_BUILD_EXAMPLES=OFF -DLIVEKIT_BUILD_TESTS=OFF \
  -DProtobuf_PROTOC_EXECUTABLE=$HOME/lk-deps/protobuf-25.3/build-host/protoc-25.3.0 \
  -DFETCHCONTENT_SOURCE_DIR_LIVEKIT_{ABSEIL,PROTOBUF,SPDLOG}=...
cmake --build build-rv1126b -j        # 8 min, exit 0

# board_loopback（独立 example 工程，对着安装好的 SDK 编）
cmake --install build-rv1126b --prefix $PWD/local-install
cmake -S cpp-example-collection -B build-examples \
  -DCMAKE_TOOLCHAIN_FILE=.../rv1126b-aarch64-linux-gnu.cmake \
  -DCMAKE_BUILD_TYPE=Release -DLIVEKIT_LOCAL_SDK_DIR=$PWD/local-install \
  -DLiveKit_DIR=$PWD/local-install/lib/cmake/LiveKit
cmake --build build-examples --target BoardLoopback -j
```

产物全部为 `ELF 64-bit LSB, ARM aarch64`：

| 产物 | 大小 |
|---|---|
| `liblivekit.so` | 9.2 MB |
| `liblivekit_ffi.so`（含 MPP codec + libwebrtc） | 22.6 MB |
| `BoardLoopback` | 10.5 MB |
